# 素材说明

代码采用MIT许可；摄影图片按各自许可证独立提供。

- `placeholder.svg`：本项目原创SVG，占位素材采用MIT。
- `app-cover.jpg`、`android/res/drawable/app_icon.png`：本项目AI辅助原创封面及图标，采用MIT，没有使用既有动画角色或场景。
- 70张菜品配图和18张餐厅配图：来自Wikimedia Commons，逐图核对CC BY、CC BY-SA或CC0许可。作者、原图页、许可、裁剪说明与SHA-256见 [图片清单](IMAGE_CREDITS.md) 和 [JSON](image-attributions.json)。方形裁剪版本保留原图许可。
- 应用设置的“图片来源与许可”展示同一清单；点击来源或许可证可用系统浏览器打开。
- 餐厅名称仅为个人记录示例。餐厅配图是品类示意，不是指定门店实拍，也不表示品牌或摄影者认可本软件。
- 菜品图为示意图，配方、烹饪方法和摆盘可能存在差异。营养数据仍为估算，不来自照片测量。
- `docs/screenshots/`：界面截图包含本项目界面及上述照片，按CC BY-SA 4.0提供，照片原作者署名见图片清单。

早期个人交付中授权不明的转载照片没有进入公开仓库。本地完整版仍单独保留全部110道菜和原图；公开版保留70道，删减见 [公开菜谱调整](public-catalog-changes.md)。

新增图片请先核对再分发许可，保留来源、作者、许可证及修改说明，并更新哈希清单。公开构建仅打包清单内且哈希匹配的图片。
